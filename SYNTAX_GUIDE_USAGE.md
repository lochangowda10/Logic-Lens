# Syntax Guide - Usage Documentation

## Overview

The Syntax Guide is a comprehensive offline reference for programming languages, designed specifically for 1st-year B.Tech students. It provides syntax, examples, rules, and Hinglish explanations without requiring any API calls.

## Features

### 1. Offline Access
- No internet required after initial load
- No API quota limits
- Instant responses
- Works in demo mode

### 2. Supported Languages
- Python
- Java
- C
- C++
- JavaScript

### 3. Coverage

Each language includes:

#### Basics
- Variables and data types
- Print statements
- Comments
- Input/Output

#### Control Flow
- If-Else conditions
- For loops
- While loops
- Switch statements (where applicable)

#### Functions
- Function definition
- Parameters and return values
- Scope and lifetime

#### Data Structures
- Lists/Arrays
- Dictionaries/Maps
- Strings
- Sets (where applicable)

## How to Use

### Browse Mode

1. Go to the "📚 Syntax Guide" tab
2. Select your programming language
3. Browse through categories:
   - Basics
   - Control Flow
   - Functions
   - Data Structures
4. Click on any topic to expand and see:
   - Syntax format
   - Working example
   - Hinglish explanation
   - Important rules

### Search Mode

1. Enter a keyword in the search box
   - Examples: "loop", "function", "variable", "if"
2. Results show matching topics across all categories
3. Each result includes full details

## Example Usage

### Scenario 1: Learning Python Loops

**Steps:**
1. Select "Python" from dropdown
2. Scroll to "Control Flow" section
3. Click on "For Loop"
4. See:
   ```python
   for variable in sequence:
       # code
   ```
5. Read Hinglish explanation:
   "Loop matlab repeat karna. Jaise railway counter pe token system - sabki baari aayegi."
6. Review rules:
   - Colon (:) required
   - Indentation mandatory
   - range(n) gives 0 to n-1

### Scenario 2: Comparing Languages

**Question:** How do I print in different languages?

**Steps:**
1. Search for "print"
2. See results for all languages:
   - Python: `print(value)`
   - Java: `System.out.println(value);`
   - C: `printf("format", variables);`
   - C++: `cout << value << endl;`
   - JavaScript: `console.log(value);`

### Scenario 3: Quick Reference During Coding

**Situation:** Forgot Java loop syntax

**Steps:**
1. Switch to Syntax Guide tab
2. Select "Java"
3. Search "loop" or browse Control Flow
4. Copy syntax template
5. Adapt to your code

## Extending the Guide

The syntax guide is modular and can be extended:

### Adding New Topics

Edit `syntax_guide.py`:

```python
"New Topic": {
    "syntax": "syntax_format",
    "example": "code_example",
    "hinglish": "explanation_in_hinglish",
    "rules": [
        "Rule 1",
        "Rule 2"
    ]
}
```

### Adding New Languages

Add new language section:

```python
"NewLanguage": {
    "basics": { ... },
    "control_flow": { ... },
    "functions": { ... }
}
```

### Adding New Categories

```python
"advanced_topics": {
    "OOP": { ... },
    "File Handling": { ... }
}
```
